Q12 - PARTIAL INDEX - BASELINE TANPA INDEX

Deskripsi:
Query mencari event dengan status='GAGAL' (sekitar 2% baris tabel).
Baseline ini menjalankan tanpa index sama sekali (hanya PK yang tersedia).

Query:
EXPLAIN (ANALYZE, BUFFERS)
SELECT event_id, terjadi_pada, jumlah
FROM lab6.event_log
WHERE status = 'GAGAL'
ORDER BY terjadi_pada DESC
LIMIT 20;
